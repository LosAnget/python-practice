# 面积计算器

我学 Python 时写的第一个小项目：一个命令行的面积计算器。

## 怎么运行

需要先装好 Python，然后在命令行里执行：

```
python area.py
```

接着按提示选择图形、输入数字即可。

## 支持的计算

| 图形 | 公式 |
|---|---|
| 圆 | S = πr² |
| 矩形 / 正方形 | S = ab |
| 三角形 | S = 底 × 高 ÷ 2 |

## 代码结构

- `read_positive()` —— 输入校验，保证拿到的是正数
- `circle_area()` / `rectangle_area()` / `triangle_area()` —— 三个计算函数
- `main()` —— 菜单循环

## 说明

只用到了 Python 标准库的 `math`，所以不需要安装任何第三方包。
